# MovieLens 🎬

MovieLens is a movie search web application built using HTML, CSS, and JavaScript.  
It allows users to search for movies and view detailed information such as posters, release year, rating, cast, and plot using the OMDb API.

## Features

- 🔍 Search for movies
- 🎬 View movie posters
- ⭐ Display IMDb rating
- 👥 Show cast and movie plot
- ▶ Watch trailer option
- 📄 Movie details page
- ⚠ Handles "Movie not found" errors

## Tech Stack

- HTML
- CSS
- JavaScript
- OMDb API

## How it works

1. Enter a movie name in the search bar.
2. The app fetches movie data using the OMDb API.
3. Movie posters and details are displayed.
4. Click on a movie to view more information.
